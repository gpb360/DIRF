# DIRF YouTube launch package

This folder is the recording-ready launch package for a five-video DIRF series.
It is grounded in the current repository, live DIRF output, official competitor
documentation, current agent-workflow standards, and YouTube's own creator
guidance.

Start production approval with `DECISION-GATE.md`. It contains the recommended
public positioning, pronunciation, repository path, anonymization boundary,
voice test, and exact recording-baseline choice.

## Launch thesis

DIRF is the preflight, routing, continuity, and evidence layer for agent work.
It lets people keep their existing agent host, skills, project rules, and
development process while giving each task a small route, clear boundaries,
canonical state, and a finish line that requires evidence.

**Campaign line:** Keep your agent stack. Give it a route, a record, and a
finish line.

## Contents

- `DECISION-GATE.md` — grouped recommended approvals and narration test
- `CONTEXT.md` — audience, constraints, success criteria, and settled decisions
- `RESEARCH.md` — market, competitor, audience, and YouTube evidence
- `ADR-001-positioning.md` — the positioning decision and rejected alternatives
- `SPEC.md` — build-ready content and production specification
- `TICKETS.md` — dependency-ordered production tickets
- `PRODUCTION.md` — capture, edit, voiceover, QA, and release workflow
- `SHORTS.md` — 25-short extraction and testing system
- `scripts/` — five voiceover-ready long-form scripts
- `visuals/` — reusable DIRF system diagram for video and thumbnails

## Current boundary

This package contains research, messaging, scripts, storyboards, and production
instructions. It does not publish anything, generate paid media, synthesize a
voice, or claim that an unreleased feature is available. Before recording,
refresh the checkout and capture every command shown at the exact commit used
in the video.
