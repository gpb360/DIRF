# visual-conformance

Inventory the whole product surface, compare it against exact approved references, fix verified issue-owned mismatches, and recapture the complete matrix.

Follow the ordered phases and capability requirements declared above.

Parity is a numeric bar per dimension, scored by fresh-context critics and
calibrated by the user's estimate. The builder's own score never decides a stop.
The round ledger is the handoff between rounds.
