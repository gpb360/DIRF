# improve-plan

Create a cost-aware execution plan before implementation. Look up repository
facts first. Treat model suggestions as preflight capability advice only. Ask
one unresolved decision at a time, recommend an answer with its real tradeoff,
and wait for the user to confirm the shared understanding before planning
implementation.

Follow the ordered phases and capability requirements declared above.
