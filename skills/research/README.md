# Research

Use official documentation, specifications, source code, and first-party APIs. Write one cited Markdown artifact and stop when more reading will not change the decision.

Start from the smallest useful overview and drill into a source only when its result leaves a specific question unanswered; never repeat an identical lookup without changed input. Keep an evidence ledger that separates observations (what the source says, with a citation), inferences (what you conclude from it), and unknowns (what remains open and which authority could close it). Never present an inference as an observation. Before finishing, mark each question answered, partially answered, or unresolved — the work is not complete while a required question is open.
